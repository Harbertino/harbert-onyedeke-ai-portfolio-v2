# Harbert Onyedeke — Applied AI & Digital Innovation Portfolio

Version 2.0 · Static HTML5, CSS3 and vanilla JavaScript. No framework, backend or build step required.

## Local preview
Open `index.html` in a browser or serve this directory with any static file server.

## Deploy
Deploy the contents of this directory as the project root to Vercel or Netlify.
- Build command: none
- Output directory: `.`
- Framework preset: Other / No framework

## Portfolio experience
- Official professional portrait in the homepage hero.
- Recruiter-first 30-second brief covering capability, delivery and evidence.
- Applied-AI project demonstrations.
- Programme impact section with documented scope.
- Six-image field gallery covering learner registration, AI learning, coding and robotics, facilitation, graduation and community engagement. Gallery images open in an accessible lightbox.
- Institutional recognition and evidence cards linking to original supplied image files, including LEAP Africa recognition, Lagos State Education District VI approval correspondence, BusinessDay Start-Up Digest clipping, and facilitator-development evidence.
- Selected AI and education credentials, CV and credential dossier.
- Responsive navigation and mobile layouts.

## Evidence integrity
Claims are based on the supplied AI in Nigeria CV, credential dossier and evidence files. Course completions and achievement badges are not represented as professional certifications. The 200+ figure refers to the 2025 DLCD / Youth Day of Service programme across seven public secondary schools; it is programme reach, not a verified unique-participant database count. The Lagos State Education District VI letter is described within its stated scope and conditions, not as an employment endorsement or blanket institutional partnership.

## Media note
The available library contained photographs and publication/recognition scans, but no source video clips were located during this build. The gallery is photo-ready; genuine workshop or facilitation footage can be added when source video files are available. No stock or generated training footage has been substituted for documentary evidence.
